# Clean Village (클린빌리지)

화면 아래 작업표시줄 위에 붙어 사는 도트 감성 마을 청소 방치형 게임이에요.
동물 청소부 주민들과 함께 버려진 마을을 치우고, 가게를 되살리고, 마을을 키워요.

## 다운로드

👉 [최신 버전 받기 (CleanVillage.exe)](https://github.com/sunsu970306-pixel/CleanVillage/releases/latest/download/CleanVillage.exe)

- 받은 `CleanVillage.exe` 를 아무 폴더에 두고 실행하면 끝이에요.
- 처음 실행할 때 Windows 가 "PC 보호" 창을 띄우면 **추가 정보 → 실행** 을 누르세요.
- 저장은 `%APPDATA%\CleanVillage` 에 되어서, exe 를 옮기거나 바꿔도 이어서 할 수 있어요.

## 업데이트

게임이 10분마다 새 버전을 확인해요. 새 버전이 나오면 알림이 뜨고,
**[설정] → [업데이트]** 를 누르면 저장 후 알아서 바꾸고 다시 켜져요.
